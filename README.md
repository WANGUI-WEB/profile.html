# Wangui-web - Personal Portfolio

Live Site: https://wangui-web.github.io/profile.html

## About
Mobile-first portfolio website built with HTML5 and CSS3 on Acode. 
Designed to load fast on 3G and work on all phone screens in Kenya.

## Features
- Responsive design: works on 320px → desktop
- Zero JavaScript: loads under 30 KB
- WhatsApp + Email contact buttons
- Project: Partitioned wedding card with gradient design
- Project: About Me page with clean mobile layout

## Projects
1. **wedding-card.html** - Partitioned invitation with top/middle/bottom sections, white gradient, and WhatsApp RSVP button
2. **about-me.html** - Personal bio page with responsive CSS, built mobile-first

## Tech Stack
HTML5 · CSS3 · Acode · GitHub Pages

## What I learned
- CSS gradients and border-radius for modern cards
- Mobile-first responsive design
- Git commit/push workflow from Acode
- GitHub Pages deployment
